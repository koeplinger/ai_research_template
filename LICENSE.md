## Why two licenses

Code is licensed permissively so that a tool can be lifted into any project
without friction. Written material carries attribution because a methodology
should be traceable to where it came from, and because a researcher who
adapts it should be able to show what they started from and what they
changed. Both licenses permit commercial use, modification, and
redistribution.

## Inherited material

None. This template imports nothing from any other repository. A project
built from this template lists every artifact it imports, with attribution
and original dates, in the ledger of `inherited/README.md`, under the
import policy stated there; this section then names the license each
import is carried under.

## In a project built from this template

Replace the copyright holder in `LICENSE-CODE` and the recommended citation
above with the project's own. Keep the split between code and written
material unless there is a reason to change it, and if there is, record the
reason here.
