# AI Research Template

**Under construction.** Start here:

- [VISION.md](VISION.md): what this template is, who it is for, and what it
  will contain. The durable statement of intent.
- [VISION_PLAN.md](VISION_PLAN.md): how the template is being built, step by
  step, and how far along it is. Ephemeral; deleted when the build is
  complete.

This repository is a *template* for AI-assisted research. It is not itself a
research project. The methodology it packages requires every research
project built from it to keep an immutable log of every prompt; that
requirement applies to those projects, not to the construction of this
template, and **no prompt log is kept for the build-out**.

## Lineage

The methodology descends from the author's first attempt,
[`leech_alg`](https://github.com/koeplinger/leech_alg)
(also on [Bitbucket](https://bitbucket.org/jenskoeplinger/leech_alg)), and
was substantially reworked in a later, private project. That project is not
named here, and nothing specific to it, or to any other project of the
author's, appears in this repository.
