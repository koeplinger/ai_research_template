# Attachments

*Created 18 November 2026; updated 18 November 2026.*

What the rounds received and keep as received: a file that the
researcher hands over with a prompt and that a second reader could not
otherwise reach, such as a reader's marked-up copy of a draft, an annotated comparison of
two versions, or a referee's report as sent. A file a second reader can
reach elsewhere is named in the entry by its locator instead, and one
that `MANIFESTO.md` §6 keeps out of the repository is replaced by the
note the entry template gives. An attachment is not an import: nothing
builds on it as evidence, and material the project builds on enters by
the route its kind has instead, such as a source under
`source_documents/README.md`, imported material under
`inherited/README.md`, or a run of one of the project's checks, whoever
made it, in that check's record.

Each file is named `NNN_short_name.<ext>`, NNN the number of the entry
that received it, and that entry names its path; a file whose name does
not begin with a number matches no row of the configuration and is
reported. Before a file is kept it is read against §6 and against what
the researcher has decided must never reach the repository
(`MANIFESTO.md` §8), since the privacy scan does not read inside a binary
file. What the file records about itself is read too: the name and the
time that annotation software records with each mark, and every field of
its properties, such as the author, the title, the dates, and the program
or device that made it.

**An attachment is never corrected.** It is immutable once committed, like
the entry that received it (`DOCUMENT_GENRES.md` §1), and the round check
reports any change to it. What the project says about it goes in the
project's own text: a later entry, or the artifact that acts on it, such
as the markup ledger of a version changelog for a marked-up copy
(`paper/_template_changelog.md`), or a review for a report
(`paper/reviews/README.md`). It carries no header stamp; the entry that
received it dates it. It keeps the terms it was received under, which
its row below records, and `LICENSE.md`, *Material under its own terms*,
relicenses none of it.
